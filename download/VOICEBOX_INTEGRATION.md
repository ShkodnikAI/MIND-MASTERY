# Инструкция по интеграции Voicebox в meditation app

## Обзор

Интеграция локального TTS-движка Voicebox для генерации презаписанных русских голосов для 75 медитационных практик (~500 MP3 файлов).

---

## Фаза 1 — Установка Voicebox

### 1.1 Клонирование репозитория

```bash
git clone https://github.com/jamiepine/voicebox.git
cd voicebox
```

### 1.2 Запуск через Docker

```bash
docker compose up -d
```

- Поднимет API на порту `17493`
- Дождаться загрузки моделей (~10-20GB, первый раз)

### 1.3 Проверка работоспособности

```bash
curl http://127.0.0.1:17493/profiles
```

Должен вернуть список доступных голосовых профилей.

### 1.4 Создание русского голоса для медитаций

- Клонировать из sample или использовать Kokoro preset
- Настроить профиль под медитативный стиль (медленный, спокойный тон)
- Запомнить `profile_id` для использования в скрипте генерации

---

## Фаза 2 — Скрипт генерации

### 2.1 Задача

Создать скрипт, который:

1. Прочитает все 75 файлов `content/texts/**/*.ru.json`
2. Для каждого ключа из `segments` отправит `POST /generate` к Voicebox API
3. Сохранит ~500 MP3 файлов в `assets/audio/voice/<practice_id>/<phase>.mp3`
4. Поддерживает resume (докачка при прерывании)
5. Логирует прогресс генерации

### 2.2 API Voicebox

**Эндпоинт генерации:**
```
POST /generate
Content-Type: application/json

{
  "text": "Текст для генерации",
  "profile_id": "<profile_id>",
  "format": "mp3"
}
```

**Ответ:** MP3 бинарные данные (audio/mpeg)

### 2.3 Структура JSON контента

Каждый файл `content/texts/<category>/<practice_id>.ru.json` содержит:

```json
{
  "segments": {
    "intro": "Текст вступления...",
    "phase1": "Текст первой фазы...",
    "phase2": "Текст второй фазы...",
    "phase3": "Текст третьей фазы...",
    "closing": "Текст завершения..."
  }
}
```

## Фаза 3 — Интеграция в приложение

### 3.1 Добавление режима голоса

Добавить `'prerecorded'` в `VoiceMode`:

```typescript
type VoiceMode = 'system' | 'prerecorded';
```

### 3.2 Resolver для аудио-ассетов

Создать `resolveVoiceUri(textKey)` в `assetResolver.ts`:

```typescript
function resolveVoiceUri(textKey: string): string {
  // Возвращает путь к MP3 файлу: assets/audio/voice/<practice_id>/<segment>.mp3
}
```

### 3.3 Обновление Audio Engine

В `useAudioEngine.ts`:

- Если `mode === 'prerecorded'` → играть MP3 через expo-av
- Иначе → использовать system TTS (текущее поведение)

### 3.4 UI — Переключатель голосового режима

Добавить переключатель в UI сессии:
- System (системовый TTS)
- Prerecorded (презаписанный голос)

## Tech Stack

- **Мобильное приложение:** React Native (Expo)
- **Аудио воспроизведение:** expo-av
- **TTS движок:** Voicebox (локальный Docker)
- **Формат аудио:** MP3

## RN хитрости

- expo-av требует абсолютных путей к локальным ассетам
- Для bundled assets использовать `Asset.fromModule(require(...)).uri`
- Следить за памятью при preload множества MP3

## Требования к голосу для медитаций

- **Язык:** Русский
- **Стиль:** Спокойный, медленный, медитативный
- **Темп:** Ниже среднего
- **Тон:** Мягкий, не навязчивый
- **Чёткость:** Хорошая дикция для понимания инструкций
